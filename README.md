# Kills Left

Shows kills left to your target level based on average XP per kill, auto-tracking combat skills gaining XP.

- Sidebar panel lists gaining skills with per-skill target level spinners + reset buttons.
- Per-skill infoboxes show compact kills left (1.2K style), hover for full numbers + progress.
- 1 kill is enough (fight-start XP snapshot, resolves after drops land).

## Run
Open `kills-left` as a separate IntelliJ project (Gradle JVM 11), Gradle `run` task.
